## Minor 1 — an in-flight older geometry response can override a superseding image-sequence status

**Location:** `manager/ui/spectator.js:219` (supersession guard), with draw at line 220 and the freshness override at line 225. Related producer behavior is `manager/spectator.py:308` (`value.sequence < native.frame_sequence`) and `_geometry_status()` returning the inactive shape with sequence zero when that frame fails freshness.

**Trigger:** An authenticated geometry request for capture sequence 9 is already in flight. Native subsequently produces image capture 10 while no newer valid geometry frame is available (for example, geometry capture was skipped because its channel was busy). A status response reaches the browser first with `geometry = {available:true, frame_available:false, sequence:0, age_ms:null, ...}` and `frame = {available:true, sequence:10, ...}`. The delayed sequence-9 geometry response then completes within the age limit and with unchanged epochs/session/backend.

**Observed result:** The guard only compares `status.geometry.sequence`; zero does not supersede nine. The browser draws geometry 9, sets `videoUnavailable=false`, and hides the waiting overlay despite already knowing image capture 10 exists. The independent read-only mounted-controller reproduction returned `{"draws":1,"detail":"640 × 360 · Geometry Frame 9 · 1 ms old","overlayHidden":true}`. It used the existing shared binary fixture, changed its epochs to 4/8 and age to zero, delayed the fetch promise, and installed the exact status shape described above before resolving it.

**Impact / severity:** A bounded stale visual update can be displayed and labelled fresh after a newer known capture. Epoch, session, authentication and the two-second maximum age checks still apply; there is no gameplay mutation or cross-session leak. Thus Minor for this experimental branch, but it weakens the intended no-superseding-frame freshness behavior. The current regression test at `tests/test_spectator_geometry_ui.js` checks a newer *available geometry* sequence and misses this actual manager shape.

**Fix:** Before drawing geometry, reject against the maximum known capture sequence for the current epoch, including `status.frame.sequence` when available, as well as `status.geometry.sequence`. Add the delayed-response regression with geometry unavailable/sequence zero and image sequence 10. If broader native supersession visibility is needed later, expose that sequence separately; this finding does not require redesigning the protocol.

## Minor 2 — supported native geometry implementation does not exclude the n-gon profile

**Location:** `native/crossplay-dedicated.patch`, the `src/Main/jkObserver.c` addition corresponding to reconstructed source line 205 (`triangles[i].v1/v2/v3`); triangle-specific function begins at reconstructed line 177. Related declaration is patch lines 3536–3537, reconstructed `src/Main/jkObserverGeometry.h:4–5`. The `rdCache.c` call is already enclosed by `#ifndef RDCACHE_RENDER_NGONS`.

**Trigger:** Compile the observer with the existing Linux SDL2 observer flags plus `RDCACHE_RENDER_NGONS`. In that profile `rdTri` is an integer typedef, so the supported body cannot access triangle members.

**Observed result:** A focused `-fsyntax-only -DRDCACHE_RENDER_NGONS` compile using the recovered compile database, redirected to the current native checkout, exits 1 with three member-access errors at `jkObserver.c:205`. An independent syntax check including only `Main/jkObserverGeometry.h` under the same flags exits 0. No objects or baseline build files were written by these checks.

**Impact / severity:** The optional alternative compile profile fails. The shipped Linux profile does not enable n-gons and remains unaffected. The earlier report's claim that the type is absent in TARGET_TWL is not substantiated and should be corrected in delivery documentation and the review ledger. No full TARGET_TWL build was attempted, and no TARGET_TWL-specific failure is asserted here.

**Fix:** Guard the triangle-specific declaration and complete function definition with the same `#ifndef RDCACHE_RENDER_NGONS` condition as the call, or otherwise exclude the supported triangle body from that profile. The whole-function guard keeps the contract clearest. Verify the focused syntax case plus the normal native observer checks when the patch/package is refreshed.

## Strengths and verified design alignment

- Native collection occurs within the existing observer render scope and copies only projected numeric vertices, opaque colour bytes and validated rebased indices. No pointer-bearing native structure or texture resource is serialized. The new path does not allocate a player or actor, configure a second camera, or introduce a gameplay transport.
- Counts and payload arithmetic are bounded before writes. Nonfinite projection, missing arrays, bad indices and excess capture size discard the whole geometry capture. Rejection diagnostics are finite and rate limited per reason across frames and lease changes.
- Independent AF_UNIX stream validation, nonblocking sends with SIGPIPE suppression, fixed native buffers, bounded send attempts, and preservation of partially transmitted envelopes prevent geometry congestion from corrupting the image stream or truncating a reused geometry stream. New captures are skipped while one envelope is pending.
- Operation 3 uses source zero and the existing authenticated supervisor request/reply path. It checks epochs and boolean activation, requires a ready observer, renews its separate lease, and leaves camera/control identity unchanged. Manager image fetching does not activate it, while authenticated geometry fetches renew the shared viewer lease. Status and input do not renew either geometry activation or viewer fetching.
- The HTTP route inherits loopback, same-origin and Bearer protection. Query names are restricted and unique; both epochs are required. Header bounds precede payload allocation, attributes and indices are validated, and invalid geometry retires only its channel. Local geometry errors are distinct from image/control errors.
- Native capture age, transfer elapsed time, matching native status age, current epochs and current session state all participate in freshness. The stale-epoch activation fix clears retry state correctly on the new epoch while preserving genuine activation failures. No additional persistent-error poisoning was found.
- The separate WebGL canvas uses the exact clip-space protocol and fixed opaque/depth profile. Switching views releases held movement without reconfiguring the observer. Request cancellation and presentation revisions reject late responses after display/session/epoch changes. Unsupported WebGL, context loss and geometry failure return to the image view.
- Tests cover wire boundaries, independent failure, viewer and activation leases, ownership, delayed responses, real numeric WebGL rendering and invalid captures. The documented real GPU fixture checks eight pixels; final live evidence checks changing stock-map payloads, paired image/geometry sequence, free/follow operation, mobile layout and close/fallback behavior. Those live tests were inspected as receipts, not rerun by this reviewer.
- Packaging documentation honestly distinguishes the two freshly compiled application units from 204 reused application objects and 12 dependency inputs. Supplied-object byte identity is distinguished from successful libsmacker source relink. I independently hashed the checked-in binary and complete patch and confirmed both match `acceptance.json` (`16944b47…` binary and `26ea7f65…` patch).
