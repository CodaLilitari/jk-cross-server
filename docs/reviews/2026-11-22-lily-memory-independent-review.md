## Important

1. **Interrupted runs can be reported as having no selection or transfer after both already happened.** `scripts/bot_development/analysis/audit_memory_learning.py:14–19,34` overwrites any reconstructed selection and unconditionally sets `transfer_executed=False`. A stopped sealed block after a genuine G8 freeze, or a stopped diagnostic after all 288 transfer attempts, produces those false statements. The incomplete path also omits `reinferred_decisions`, which the CLI unconditionally prints after creating its output, so it exits with a KeyError and leaves an output that cannot be overwritten. Partial attempt entries at `run_memory_learning.py:242,258,266` lack candidate/episode IDs. Preserve the actual freeze, separate attempted/completed transfer, compute totals on all exits, and label every assignment. Add CLI-level tests for interruption before selection, mid-transfer, and after transfer.
2. **The offline auditor does not enforce the stop boundary or all publication boundaries on incomplete runs.** `run_memory_learning.py:236–273,311–325,337–344,498–505`; `audit_memory_learning.py:14–20`. Inventory checks across the tree run only at successful finish. A missing calibration block with a later sealed attempt subtree is silently reported as an unrun calibration; a non-prefix subset of the ledger can likewise be accepted. An interrupted claim before publishing assignment.json, partial model publication, or missing ranking after a completed block raises a generic exception without presenting the valid prefix. The partial-only assignments/block sidecars are not validated even when they contain a complete, contradictory JSON object. Use prerequisite-ordered inventory/prefix validation analogous to the old offline auditor, distinguish truncation from contradiction, preserve claimed and unrun identities, and reject any seal opening after a closed gate. Regressions should include an extra later-stage attempt, a gap in the claim prefix, and interruption during claim/ranking/model publication.
3. **Contradictory available evidence can pass as censored.** `memory_rollouts.py:155–163,226–232,236–237,255–265`; `run_memory_learning.py:262–265`. In a one-tick synthetic memory fixture I set engine wait to 0, worker wait to 7, retained the native died terminal, and blanked the absent marker. Audit classified the contradictory terminal and known engine exit as censored. A complete assigned record lacking seed and position also passed when no observation/origin could be joined. The new legacy path returned censored. It calls old.audit_attempt but omits the prior offline auditor's interrupted_controls pass. Bind a known engine exit directly to a present terminal, validate individually available assignment/origin/goal/first-observation witnesses against their fixed or paired references, and recheck available legacy/native controls beyond the journal. Add fixtures for all three reproductions. A late failure with otherwise consistent traces must stay unscored.
4. **The run claim does not uniquely claim the declared budget.** `run_memory_learning.py:359–368,534–536,293`. The basename and symlink checks allow two ordinary absolute output paths with the same RUN_ID in different parent directories. Bind execution to one declared canonical path or a shared create-only declaration/run claim, allow portability separately for offline reads, and enforce the worker cap at the execution boundary. Test a second parent and three workers without launching any games.

## Minor

- `bots/lily/motor_memory.py:81` clips the retention logit to ±40 before raising retention to a fractional elapsed-time power. For allowed a=-1000 and tick_ms=1 the previous-state coefficient becomes about 0.368, whereas the specified formula gives about 1.39e-11. The declared search starts well inside that range. A stable log-sigmoid followed by exponentiation preserves the declared recurrence for all bounded models.
- `bots/lily/motor_memory.py:91` silently initializes a zero state if the entire context.state field is missing. The experiment’s Session always supplies it, but a standalone caller can accidentally reset history mid-episode. An explicit missing-state failure, or a documented designated episode-start convention with a test, would make that ABI behavior clear.
