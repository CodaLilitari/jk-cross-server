01 / SESSION

Choose the game

All players need matching game content. JK and MotS run as separate sessions. The legacy password prompt is not an access-control boundary across these transports.

MotS defaults to personality mode. Use rank 7 for compatibility with all clients; lower ranks require ranked Jedi mode (additional game flag 4096).

A limit of 0 disables that limit. Retail sessions allow up to 15 playing clients and a 100–300 ms tick interval. The dedicated host is added separately; a map may support fewer players than the advertised limit.

02 / CONTENT

Local files

The browser verifies downloaded files and restarts when a mod change requires it. Players still need their own original game data. Retail and native players install matching custom content themselves.

03 / CONNECTIONS

Client transports

127.0.0.1 accepts local browser clients. Use 0.0.0.0 to listen on the server's network interfaces. The control panel always stays local.

BOT BEHAVIOR / LIVE RULES

Combat rules

Peace ends temporarily after attacks, hostile Force use, persistent body blocking, or rapid weapon switching nearby. Saber-only and Force use are independent settings. During play, Apply bot rules updates the running bots without restarting the match.

PERSISTENT / CHAT ADMIN

Admin credentials

Issue a separate key for each administrator or device. Keys survive game starts and panel restarts. Revoking a key removes its authority on the next command.

Reading credential metadata…

The download is a private credential container with a .cog extension. Keep it outside game folders and archives; do not load it as a game script. It is shown only through this download. Rotate a lost key to revoke it and download a replacement.

Use a key in retail, OpenJKDF2, or JKWeb
  1. Download and extract the offline helper, then open admin-helper.html locally.
  2. In the game, enter admin login. Copy the server's private JKADMIN1 challenge.
  3. Select your key file in the offline helper and paste the challenge. Copy its generated admin prove … line into game chat.
  4. After authentication, use admin help, admin players, admin next level, or admin kick #slot (or an exact name), according to your key's capabilities. Use admin logout when finished.

The helpers work offline and never send the key. Ordinary peer chat may display the one-time proof. A challenge lasts two minutes; authentication lasts 15 minutes on the same connection and ends on a session reset.

Use only the response to your own login. Never answer a challenge forwarded by another player; the offline helper cannot authenticate the chat sender.
